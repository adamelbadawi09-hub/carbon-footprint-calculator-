GitHub & Pages Deployment Guide
Complete these steps to generate the 2 required links for Schoology submission before 21 October 2026.
Step 1: Save Your File

Save this entire code snippet on your computer as index.html.

Step 2: Create a Public GitHub Repository
  1. Go to GitHub.com and sign in.
  2. Click the "+" icon at the top right and select New repository.
  3. Name your repository (e.g., carbon-footprint-calculator).
  4. Ensure the repository visibility is set to Public (Required).
  5. Click Create repository.
Step 3: Upload index.html
  1. In your new repository page, click uploading an existing file.
  2. Drag and drop your index.html file.
  3. Click Commit changes.
Step 4: Enable GitHub Pages (Get Live URL)
  1. Inside your repository, go to the Settings tab.
  2. On the left menu, click Pages.
  3. Under Build and deployment > Branch, select main (or master) and click Save.
  4. Wait 1-2 minutes and refresh the page until you see: "Your site is live at https://yourusername.github.io/carbon-footprint-calculator/".
